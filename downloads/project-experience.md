# 프로젝트 경험 문서 — 「SYMBION」 비주얼 콘셉트 및 인게임 리소스 제작

## 프로젝트 개요

- 장르: 2D 횡스크롤 액션 로그라이크
- 콘셉트: 생체 실험체가 기생체의 능력을 활용해 연구 시설을 탈출하는 바이오펑크 세계관
- 담당 업무: 비주얼 콘셉트 수립, 비주얼 가이드 작성, 캐릭터·레벨·UI 리소스 기획 및 제작

## 상황(Situation)

팀 프로젝트 「SYMBION」에서 비주얼 콘셉트와 인게임 리소스 제작을 담당했습니다. 프로젝트는 바이오펑크 세계관의 2D 플랫포머 액션을 목표로 했지만, 아이데이션 초기에는 팀원마다 ‘바이오펑크’에서 떠올리는 이미지가 달랐습니다. 이 상태에서 각자 리소스를 제작하면 캐릭터와 배경, UI가 서로 다른 게임처럼 보이거나 게임에 필요한 정보가 시각적으로 잘 전달되지 않을 가능성이 있었습니다.

따라서 추상적인 장르 이미지를 팀이 함께 판단할 수 있는 구체적인 기준으로 바꾸고, 캐릭터 및 레벨 기획을 실제 게임 화면에 사용할 수 있는 리소스로 연결해야 했습니다.

## 과제(Task)

제 목표는 다음 두 가지였습니다.

첫째, 팀원들이 같은 방향으로 리소스를 제작하고 피드백할 수 있도록 「SYMBION」만의 시각 언어와 제작 기준을 정리하는 것이었습니다.

둘째, 기획서에 적힌 캐릭터와 공간의 특징을 게임 화면에서 즉시 알아볼 수 있는 형태로 변환하고, Unity에서 적용 가능한 인게임 리소스로 제작하는 것이었습니다. 이 과정에서 바이오펑크의 기괴함은 유지하되 과도한 장기·혈액 표현은 줄이고, 전투 중에도 캐릭터와 지형이 구분되도록 가독성을 확보해야 했습니다.

## 행동(Action)

### 1. 레퍼런스를 ‘분위기 자료’가 아닌 제작 기준으로 정리했습니다.

「Blasphemous」와 「Rain World」 등 횡스크롤 게임의 사례를 수집한 뒤, 단순히 비슷한 이미지를 나열하지 않고 각 레퍼런스에서 가져올 요소를 색상, 실루엣, 재질, 화면 깊이, 정보 가독성으로 나누어 분석했습니다.

이를 바탕으로 아이보리·다크 그레이·블랙·크림슨을 중심 색상으로 정하고, 장기와 혈액의 직접적인 노출은 제한하며 촉수도 한 개에서 두 개만 사용하도록 했습니다. 대신 비대칭 신체, 발광하는 눈, 기생체가 팔다리와 무기로 변형되는 실루엣을 강조해 프로젝트의 기괴함을 표현했습니다. 이렇게 ‘무엇을 넣을지’뿐 아니라 ‘무엇을 제외할지’까지 문서화하여 팀이 같은 기준으로 시안을 판단할 수 있게 했습니다.

### 2. 레벨 리소스와 화면의 정보 구조를 분리했습니다.

레벨 리소스를 Background, Tile, Structural, Gameplay Object, Decoration, Foreground의 6종으로 구분했습니다. 또한 화면을 전경·중경·배경의 3개 깊이로 나누고, 플레이어가 밟거나 상호작용하는 요소와 분위기 연출용 요소가 명도와 배치에서 구분되도록 설계했습니다.

초기 시안에서 배경의 디테일이 플레이 공간보다 두드러지는 문제가 나타났을 때는 장식 요소의 대비를 낮추고, 구조물의 외곽과 상호작용 오브젝트의 색상 차이를 강화했습니다. 작업 시트 역시 4096px 기준에서 2048px 또는 1920px 기준으로 조정해 실제 게임 화면에서 확인하기 쉬운 크기로 정리했습니다.

### 3. 기획 의도를 캐릭터와 UI 리소스로 구체화했습니다.

주인공은 실린더에 수감된 사지 결손 실험체가 기생체를 장착하면서 팔·다리·등을 복원하고 무기화한다는 설정을 중심으로 디자인했습니다. 일반 몬스터, 엘리트, 보스는 체형과 공격 부위의 실루엣만으로도 위계와 공격 방식을 구분할 수 있도록 형태를 달리했습니다.

UI와 이펙트는 게임의 핵심 색상을 유지하면서도 기능을 먼저 알아볼 수 있게 제작했습니다. 예를 들어 버튼에는 형광 하늘색 테두리를, 패널 경계에는 연두색을 적용하고, 스킬 강화는 형광 녹색 화살표와 ‘UP’ 표기로 즉시 인지할 수 있도록 했습니다.

### 4. 결과물을 반복해서 비교하고 수정했습니다.

가이드 문서를 기준으로 캐릭터, 레벨, UI 시안을 팀에 공유하고 피드백을 받았습니다. 시안이 기획 의도와 다르거나 인게임 가독성이 부족할 때는 이미지를 그대로 고치는 데 그치지 않고, 어떤 기준이 부족했는지 가이드에 다시 반영했습니다. 또한 Obsidian으로 결정 사항과 수정 이유를 기록하고, Photopea로 시안의 크기·색상·가독성을 보정해 팀원이 수정 전후의 차이를 확인할 수 있도록 했습니다.

## 결과(Result)

- 색상, 표현 수위, 실루엣, 화면 깊이를 포함한 비주얼 가이드 문서를 제작했습니다.
- 레벨 리소스를 6개 유형, 화면을 3개 깊이로 분류하여 제작물의 용도와 배치 기준을 명확히 했습니다.
- 주인공과 일반·엘리트·보스 몬스터, 레벨 배경 및 구조물, UI와 강화 이펙트 등 기획을 인게임 리소스로 구체화했습니다.
- 추상적이었던 ‘바이오펑크’라는 방향을 제한 색상, 비대칭 실루엣, 직접적인 고어 표현 제한이라는 공통 규칙으로 전환했습니다.
- 최종적으로 Unity에서 시각 요소를 배치하고 확인할 수 있는 형태까지 제작하여, 문서의 콘셉트가 실제 플레이 화면으로 연결되는 과정을 경험했습니다.

※ 최종 제출 전 보완할 수치: 제작 리소스 총수, 가이드 페이지 수, 피드백 및 수정 횟수, 프로젝트 기간, 팀 인원, 실제 적용 완료 비율.

## 배운 점(Learning)

이 경험을 통해 비주얼 기획은 좋은 이미지를 만드는 일에 그치지 않고, 여러 사람이 같은 판단을 내릴 수 있는 기준을 설계하는 일이라는 점을 배웠습니다. 특히 장르명이나 감성어처럼 해석의 범위가 넓은 표현은 색상, 형태, 표현 수위, 기능별 우선순위처럼 확인 가능한 규칙으로 바꿔야 협업에 사용할 수 있었습니다.

또한 결과물의 완성도를 높이기 위해 세부 표현부터 수정하기보다, 먼저 해당 리소스가 전달해야 할 정보와 화면에서의 역할을 확인해야 한다는 점을 배웠습니다. 이후 프로젝트에서는 작업 전에 목적과 판단 기준을 먼저 합의하고, 시안 제작 → 인게임 확인 → 피드백 기록 → 가이드 갱신의 순환 구조를 적용하겠습니다.

## 한 문단 요약

팀 프로젝트 「SYMBION」에서 바이오펑크 세계관의 비주얼 콘셉트와 인게임 리소스 제작을 담당했습니다. 팀원마다 달랐던 장르 해석을 통일하기 위해 레퍼런스를 색상·실루엣·재질·화면 깊이로 분석하고, 4개의 중심 색상과 표현 수위, 비대칭 신체 및 발광안 등의 시각 규칙을 문서화했습니다. 또한 레벨 리소스를 6개 유형, 화면을 3개 깊이로 분류하고 캐릭터·배경·UI 시안을 Unity에서 확인 가능한 리소스로 구체화했습니다. 이를 통해 비주얼 기획은 이미지를 제작하는 것뿐 아니라, 여러 사람이 같은 기준으로 판단하고 수정할 수 있는 구조를 만드는 일임을 배웠습니다.
